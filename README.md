# RF Desense Toolbox

A comprehensive RF desense analysis tool for multi-radio coexistence design.

## Features

- **RF Architecture Builder** — interactive antenna group builder with live SVG block diagram
- **Desense Calculator** — cascaded NF (Friis), noise floor, and desense for LoRa, BLE, LTE (LB/UB), WiFi (2.4G/5G), GNSS
- **Range Estimation** — multi-model path loss (Free Space, Hata, COST-231, IEEE 802.11) with link budget
- **Desense Dashboard** — aggregated desense matrix across all radios with conditional formatting
- **Range Dashboard** — aggregated range impact matrix
- **PDF & Excel Export** — professional reports with dark/light theme support
- **Mobile Responsive** — works on phones, tablets, and desktops

## Usage

Open `index.html` in any browser, or visit the hosted version:

**🔗 [Live Demo](https://yourusername.github.io/rf-desense-toolbox/)**

> Replace `yourusername` with your GitHub username after enabling GitHub Pages.

## Supported Radios

| Radio | Frequency |
|-------|-----------|
| LoRa (EU/NA) | 867–925 MHz |
| BLE 2.4 GHz | 2.4 GHz |
| LTE Low Band | 600–900 MHz |
| LTE Upper Band | 1700–2700 MHz |
| WiFi 2.4G | 2.4 GHz |
| WiFi 5G | 5 GHz |
| GNSS | 1575 MHz |

## Setup GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set Source to **main** branch, root folder
4. Your tool will be live at `https://yourusername.github.io/rf-desense-toolbox/`
